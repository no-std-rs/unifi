ONE BINARY. YOUR SETTINGS.

Make it yours.

Use a GUITION ESP32-2424S012-V1.0 with 4 MB flash and a USB data cable. The installer supports this board’s GC9A01 display and CST816 touch wiring.

Connect with a Site Manager API key to discover your consoles and devices, or choose a local controller connection. Cloud access requires an online console running UniFi OS 5.0.3 or newer. Installation replaces the device firmware; the installer lets you choose whether to erase its flash.

02 Connect to UniFi

Let setup do the rest.

Find your gateway, verify its certificate, and create a local display key with one console sign-in.

First, start the local helper

On a computer connected to your gateway’s LAN, download the helper and run it with Python 3.10 or newer. Keep its terminal open during setup.

Download setup helper ↓python3 setup-display.py

Your console password goes only through the helper on this computer to the verified gateway. It is never saved or sent to this website.

Start the helper once, then open guided setup. Your Wi-Fi settings stay here.

Import settings from the helper

Create in Site Manager → Settings → API Keys. Used for discovery at api.ui.com, including through the optional local helper; never written to the display.

Cloud access is for setup only. The root gateway is selected when its MAC address matches the console. A personal key needs console ownership; organization keys need access to the console.

Device’s local connection

The display connects directly over your LAN, without cloud access. It needs a separate local key and the local controller’s certificate.

Use the gateway’s LAN HTTPS address with /proxy/network/integration. Self-hosted Network usually uses port 8443 and /integration.

Create this key in Network → Integrations. Your Site Manager cloud key cannot replace it. The local key goes only to the display over USB.

Copy it from the controller certificate you trust. The display pins that exact certificate and checks the TLS handshake. Update this setting after certificate rotation.

Choose a site and device

Leave an ID empty only when there is exactly one matching site or device. The display asks for an explicit ID when there are several.
